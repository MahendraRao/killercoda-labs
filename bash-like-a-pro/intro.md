# Bash like a pro, for real

This is the hands-on partner of the article
[Bash Like a Pro](https://mahendrarao.com/learn/bash-like-a-pro/).
You do not need to have read it first, but it helps. It is easier if you have done the earlier Bash labs.

## How it works

The terminal on the right is a **real Linux machine** (Ubuntu). You do not install anything.
You type commands, then press **Check** to see if you did it right.

**The kitchen idea.** A script is a **recipe card**. A pro card has blanks that the waiter fills in (**arguments**), switches on the order slip (**options**), a rule to **wash up even when the dish burns** (**trap**), and a **menu board** with names instead of numbers (**associative arrays**). In four steps you will:

1. Fill the blanks: take arguments, with a default and a usage message.
2. Read switches like `-v` and `-t 4` with `getopts`.
3. Fix a script that leaves a mess behind when it fails.
4. Count words with an associative array.

If **Check** says something is wrong, read the message. It tells you what it found and how to fix it.

Press **Start** when you are ready.
