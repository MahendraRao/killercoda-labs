# killercoda-labs

Hands-on labs for [mahendrarao.com/learn](https://mahendrarao.com/learn/). Each folder is one Killercoda scenario: a real Linux terminal, step-by-step tasks, and a **Check** button that tells you what went wrong.

| Lab | Companion article |
|---|---|
| `bash-first-script` | [Your First Bash Script, From Zero](https://mahendrarao.com/learn/bash-script-from-zero/) |

Every step's check script was tested against wrong, partial and correct answers before publishing.

Never commit secrets here. This repository is public.
