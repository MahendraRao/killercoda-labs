# Pipes, text tools and logic, for real

This is the hands-on partner of the article
[Bash Pipes, Text Tools and Logic](https://mahendrarao.com/learn/bash-pipes-text-and-logic/).
You do not need to have read it first, but it helps.

## How it works

The terminal on the right is a **real Linux machine** (Ubuntu). You do not install anything.
Two practice files were just placed in your home folder:

- `kitchen.log`: the kitchen's diary (INFO, WARN and ERROR lines).
- `orders.csv`: today's orders, columns separated by commas.

**The kitchen idea.** Each command is a **small kitchen tool**. A **pipe** (`|`) is the conveyor belt that hands one tool's output to the next. In four steps you will:

1. Count the burnt orders.
2. Rank the dishes by how often they were ordered.
3. Total the day's revenue.
4. Write a script that sounds an alarm only when something is wrong.

Each step ends with a **Check** button that tells you what it found. Wrong answers are fine, the message tells you how to fix them.

Press **Start** when you are ready.
